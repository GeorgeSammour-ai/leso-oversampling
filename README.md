# LEO: Latent-Structure Entropy Allocation

This repository provides the official implementation of the **Latent-Structure Entropy Allocation (LEO)** 

LEO addresses class imbalance by controlling how minority class influence learning using uncertainty information derived from a latent representation for binary imbalanced classification problems. It generates synthetic minority samples by identifying uncertain regions of the feature space and allocating samples to those regions using entropy-guided weighting.

---

## Official Implementation

Main implementation file:

```
src/leo_csv_tool.py
```

The experiments reported in the manuscript correspond to the **submitted** mode of this implementation.

To reproduce the algorithm used in the paper:

```bash
python src/leo_csv_tool.py --input path/to/dataset.csv --mode submitted --target_pct 100
```

---

## Method Overview

LEO is a reliability-oriented learning method for imbalanced tabular data that uses a latent mixture model to determine where synthetic minority samples should be generated.

The procedure operates as follows:

1. A Gaussian Mixture Model (GMM) identifies latent regions of the feature space.
2. Within each region, the class composition is evaluated and class-mixture entropy is computed.
3. Regions with higher uncertainty and stronger imbalance receive more synthetic samples.
4. Minority anchor samples are selected according to local entropy.
5. New samples are generated by interpolation between nearby minority neighbors.

The goal is to focus oversampling on decision-boundary areas rather than dense minority clusters.

## Installation

Clone the repository and install dependencies:

```bash
git clone https://github.com/GeorgeSammour-ai/leso-oversampling.git
cd leso-oversampling
pip install -r requirements.txt
```

---

## Command Line Usage

Run LEO on a CSV dataset:

```bash
python src/leo_csv_tool.py --input path/to/dataset.csv --mode submitted
```

Optional parameters:

```
--output path/to/output.csv
--seed 11
--target_pct 100
```

The tool will prompt you to:
- choose the label column
- specify minority and majority labels
- optionally remove ID columns

## Graphical Interface
